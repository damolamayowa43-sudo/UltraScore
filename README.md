# Ultrascore

A blue-and-black live score website starter with a public scoreboard, filters, admin dashboard, and a local natural-language assistant.

## Run
Open `index.html` in a browser, or deploy the folder to GitHub Pages / Netlify.

## Important
This starter stores data in the browser using localStorage. That means edits are only visible on the same browser/device. For public real-time scores and secure admin access, connect a backend such as Supabase/Firebase and a licensed sports-data API. Never put secret API keys directly in frontend JavaScript.
